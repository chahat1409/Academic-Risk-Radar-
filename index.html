About This Project

Project Introduction

Academic Risk Radar is a Student Academic Performance Monitoring System designed to help faculty members review student academic records and identify students who may need academic improvement.

Problem Statement

In educational institutions, tracking student academic performance manually is time-consuming and error-prone. Faculty members need a quick, visual way to monitor attendance, internal marks, assignments and quiz scores so that at-risk students can be identified early and given the help they need.

Project Objectives

  • Provide a centralised dashboard for academic performance monitoring.
  • Calculate an overall academic score using a transparent, weighted formula.
  • Classify students into Low, Medium and High risk categories.
  • Generate actionable improvement recommendations.
  • Visualise performance analytics through CSS-based charts.
  • Monitor attendance and highlight defaulters.
  • Allow generating and printing reports and exporting data as CSV.

Technologies Used

HTML5 CSS3 Vanilla JavaScript LocalStorage CSS Grid & Flexbox Responsive Design

Main Functionalities

  • Interactive dashboard with live statistics and risk distribution.
  • Full CRUD operations for student records with validation.
  • Search, filter and sort capabilities.
  • Academic risk analysis with weighted scoring.
  • Performance analytics with CSS-based bar charts.
  • Attendance monitoring with status badges.
  • Report generation, browser printing and CSV export.
  • Data persistence using browser LocalStorage.

Limitations

  • This is a frontend-only demonstration project; there is no backend server or database.
  • Student records are stored locally in the current browser using LocalStorage.
  • Data will not synchronise across different browsers or devices.
  • Clearing browser data will remove all stored records.
  • The risk calculation uses a simple rule-based system, not AI or machine learning.

Future Scope

  • Integration with a backend server and database for persistent storage.
  • User authentication and role-based access control.
  • Email notifications for at-risk students.
  • Advanced analytics with trend analysis over multiple semesters.
  • Integration with university student information systems.
